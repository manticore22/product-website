Getting Started

01

Download Files

Download both the Backstage control panel and Stage display HTML files. Save them in the same folder for easy access.

02

Open Backstage

Open verily-backstage-complete.html in your browser. This is your main control panel with all 18 tabs.

03

Configure APIs

Go to Tab 3 (APIs) and configure your preferred services:
• Ollama (local AI) or Anthropic Claude (cloud AI)
• Tavily (web search)
• ElevenLabs (text-to-speech)

04

Open Stage Display

Click "🎬 Open Stage" in Tab 7. This opens the avatar display window. Arrange windows side-by-side.

05

Enable Features

In Tab 2 (Chat), enable web search and configure settings. Test with quick test buttons or voice chat in Tab 4.

06

Start Interacting

Use text chat, voice commands, or quick test buttons to interact. Verily will respond with speech, animations, and real-time information!
